# GDC Metadata View

**GDC Metadata View** is a professional-grade web application, running entirely in the browser (100% local processing), designed for detailed side-by-side analysis and comparison of technical and production metadata for media files (video, audio, images, and Sony sidecar XML).

The application now has an interface available in **Romanian, English, and Spanish**, with a language switcher (RO/EN/ES) in the header. The language preference is saved locally in the browser (`localStorage`) and remembered on future visits.

---

## 🚀 Key Features

- **100% Local Analysis (Privacy First):** All files are processed directly in your browser. No media file is ever uploaded to external servers.
- **Side-by-Side Comparison:** Load multiple files at once to compare technical parameters in a dynamic table.
- **Sony Sidecar XML Support:** Automatically matches MP4/MOV clips from Sony cameras with their `.XML` sidecar files (or extracts the XML metadata directly from embedded sample packets) to display the **Log / Gamma** profile (S-Log3, S-Gamut3.Cine, etc.), **Exposure Index (EI)**, **color** data, and more.
- **Per-Frame Capture Settings (RTMD Track):** Extracts real on-set parameters from the first frame: **ISO, shutter/exposure time, aperture (f-stop), white balance**.
- **EXIF & GPS Analysis for Images:** Displays camera model, lens, exposure time, ISO, focal length, and exact GPS coordinates.
- **ID3v2 Tags for Audio:** Extracts title, artist, album, and genre for MP3 files.
- **Advanced Filtering & Search:**
  - Automatic highlighting of differences between files.
  - Hide identical rows for quick inspection.
  - Instant search by parameter (e.g. *Gamma, Codec, ISO, FrameRate*).
- **Multilingual interface (RO / EN / ES):** Language switcher in the header, with the preference saved in `localStorage`.
- **Report Export:**
  - **PDF:** Automatically structured and styled comparison report on an A3 landscape page. The file name includes the selected language (e.g. `metadata_report_EN.pdf`).
  - **JSON:** Structured export of all extracted data for further processing (e.g. `metadata_report_EN.json`).

## 🛠️ Technologies Used

The application is built as a **Single Page Application (SPA)**, 100% vanilla HTML + CSS + JavaScript (no frameworks), using:

- **HTML5 & CSS3 Vanilla** (modern interface with a full Dark UI theme).
- **[MediaInfo.js](https://github.com/emscripten-ports/MediaInfoLib)** – multimedia container parsing.
- **[exifr](https://github.com/MikeKovarik/exifr)** – EXIF & GPS metadata extraction from images.
- **[jsPDF](https://github.com/parallax/jsPDF)** & **[html2canvas](https://github.com/niklasvh/html2canvas)** – PDF report generation.

## 📖 How to Use

1. **Open the application:**
   - Double-click `index.html` to open it locally, or visit the link generated by **GitHub Pages**.
2. **Choose a language:**
   - Use the **RO / EN / ES** switcher in the header. The preference is saved in your browser.
3. **Load your files:**
   - Drag and drop one or more media files (video, audio, image, Sony XML) into the drop zone, or click the box to select them.
4. **Analyze & Compare:**
   - Files appear side-by-side in the table.
   - Check **Highlight differences** to quickly spot mismatches.
   - Use the search box to find a specific parameter.
5. **Export:**
   - Click **Export PDF** to download a technical inspection sheet (`metadata_report_EN.pdf`).
   - Click **Export JSON** to save the raw data (`metadata_report_EN.json`).
